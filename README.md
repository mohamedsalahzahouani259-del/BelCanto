# Bel Canto Hammamet — Restaurant Italien & Méditerranéen 🍕🍝

Site web officiel, ultra-premium, responsive et élégant pour le restaurant gastronomique **Bel Canto Hammamet** situé à Hammamet, Tunisie.

## ✨ Caractéristiques & Stack Technique

- **100% Pure HTML5 & CSS3** (Aucun JavaScript, aucun framework, 0 dépendance externe).
- **Design Éditorial Haut de Gamme :** Typographies raffinées (Playfair Display, Montserrat, Plus Jakarta Sans), palette signature (Turquoise Profond `#2F889F`, Or `#C8A96B`, Sombre `#24363A`).
- **100% Responsive :** Adapté à tous les écrans (Desktop, Tablettes, Mobiles 360px+).
- **Photos Authentiques :** Utilisation exclusive des visuels réels du restaurant et des créations culinaires.
- **Réservation Directe :** Déclenchement d'appel instantané vers le `+216 99 355 338`.
